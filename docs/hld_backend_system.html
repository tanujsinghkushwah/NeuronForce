Decision 1

⚖️ Modular Monolith vs. Microservices

Why We Rejected Microservices:
In enterprise CRMs, moving an opportunity to Closed Won must atomically update deal revenue, recalculate customer contact status, append an activity timeline entry, and refresh ARR forecasting.

In microservices, this requires complex distributed transactions (2PC or Sagas) prone to partial failure.

Our Solution: A unified ASGI application with strict domain package isolation, sub-millisecond in-process function calls, and atomic db.commit() transactions.

⚡ Uvicorn ASGI Server (uvloop)

Async event loop capable of 15,000+ RPS with non-blocking I/O for external AI gateways.

03 / RELATIONAL CP STORAGE & SCALE ROADMAP
Decision 2 (CAP Theorem)

🗄️ Relational CP Consistency

PostgreSQL (Production) / SQLite (Development)

In financial CRM systems, Consistency strictly trumps Availability.

If an upstream network partition occurs, it is significantly better to reject an update or return a retry than permit conflicting writes where two sales reps or automated AI agents overwrite contract values or pipeline stages.

Why NoSQL Was Rejected:
Eventual consistency (MongoDB / DynamoDB) introduces "dirty reads", leading to pipeline forecast drift, race conditions, and compliance audit violations.

Enterprise Scale-Out Roadmap (MVP ➔ 1,000,000 DAU)

1. PgBouncer Connection Pooler

Transaction pooling supporting 10,000+ concurrent database connections with minimal memory overhead.

2. Read-Replica Query Splitting

Routes heavy analytical queries (/api/analytics/* & search) to replicas while preserving primary node for deal writes.

3. Redis Cluster (Cache & Rate Limits)

Sliding-window agent session store cache & dashboard KPI caching (60s TTL) with per-tenant token bucket limits.

4. Asynchronous Celery / Temporal Workers

Offloads long-running AI batch runs (e.g. scoring 50,000 contacts) to background workers with SSE updates.

5. Multi-Tenant Row-Level Security (RLS)

PostgreSQL tenant_id policies ensuring 100% cryptographic tenant isolation.
